# Data-Analysis-and-Visualisation

A collection of data analysis and visualization projects built using Python, Pandas, Matplotlib, Seaborn, and Plotly.

This repository focuses on developing practical skills in **data cleaning, exploratory data analysis (EDA), data visualization, statistical analysis, and extracting insights from datasets.**

## 📂 Projects

### 🍽️ Zomato Restaurant Data Analysis

An exploratory data analysis project using restaurant data to understand:

* Restaurant categories
* Restaurant ratings
* Approximate cost for two
* Online ordering
* Table booking
* Customer votes
* Relationships between rating, votes, and cost

**Techniques used:**

* Data cleaning
* Missing-value analysis
* Duplicate checking
* Value counts
* GroupBy and aggregation
* Exploratory Data Analysis
* Correlation analysis
* Statistical visualization
* Interactive visualization

**Visualisation libraries:**

* Matplotlib
* Seaborn
* Plotly

📓 **Notebook:** `Zomato_Restaurant_Analysis.ipynb`
